***

命令行界面（CLI）简介

GUI 与 CLI

- GUI（图形用户界面）：拥有可交互的图形元素，如按钮。
- CLI（命令行界面）：用户输入命令并查看屏幕输出。
- 终端：CLI 的窗口界面，接收命令并显示结果。
- 在服务器上通常只有 CLI，没有图形界面。
- CLI 更高效，适合批量操作也功能更强大。

***

CLI 的提示符与身份

- '\$' 表示普通用户，'\#' 表示 root 用户。

***

常用 Linux 命令

- pwd：显示当前路径
- ls：显示目录内容，常与 -a（全部）、-l（详细）、-R（递归）、指定目录参数一起用
- cd：切换目录
- history：显示历史命令
- clear：清屏
- mkdir：创建目录
- touch：创建空文件
- rm：删除文件或目录
- mv：移动或重命名文件
- cp：复制文件或目录
- cat：输出文件内容
- uname -a：查看系统内核信息
- sudo：以超级用户权限执行命令

***

包管理器简介

- 在 Linux 上安装软件多用包管理器（如 apt）。
- 包管理器功能包括：下载安装、管理依赖、升级和移除软件。
- APT 是 Ubuntu 的默认包管理器，更新索引用 sudo apt update，安装包用 sudo apt install。
- APT-GET 是更老的 CLI 工具，命令略有不同。
- 有些新应用未收录于官方仓库，需手动添加仓库源或使用 Snap、AppImage、Ubuntu 软件中心等。
- Snap 鼓励跨发行版统一打包，但体积大；APT 适合特定发行版，依赖共享，占用更小。
- PPA（个人包档案）常由社区维护，添加需谨慎。

***

Linux 发行版

- 同源发行版根据软件包管理器分类，如基于 Debian 的 Ubuntu、Mint、Debian 多用 APT/apt-get，基于 Red Hat 的 CentOS、Fedora 用 yum。
- 包管理器决定了发行版间的主要技术差异。

***

Vi/Vim 文本编辑器

- Vi/Vim 是 Linux 经典内置编辑器。
- 常用两种模式：命令模式（默认）、插入模式（编辑文本），按 i 进入插入、Esc 返回命令。
- 常见命令：:wq 保存后退出，:q! 丢弃更改，/pattern 搜索，:%s/旧/新/g 批量替换。

***

Linux 用户与权限

- 每个用户有用户名（可改）和唯一 UID（数字，系统用，不能改）。
- 三类用户：root 超级管理员、普通用户、服务用户（如 mysql 专属用户）。
- 多用户有利于权限分级和操作可追溯性。

***

权限控制

- 用户/组对文件有三类权限：读取、写入、执行（rwx）。
- chown 可更改所有者，chmod 改变权限，支持符号和数字方式（如 740 代表 owner: rwx，group: r，other: 无权限）。

***

管道与重定向

- 通过管道“|”将一个命令输出作为下一个命令输入。
- 通过重定向“>”写入文件，“>>”追加写入。
- 常用组合如：“cat file | less”、“history | grep sudo > sudo-commands.txt”。

***

Shell 脚本

- Shell 脚本允许将命令批量写入文本（.sh 文件）实现自动化。
- 需给文件添加可执行权限（sudo chmod u+x file.sh）。
- 首行为 \#!/bin/bash 指定解释器（shebang），bash 脚本可定义变量、条件、循环、函数，适合自动化配置、批量运维。

***

环境变量

- 环境变量为 KEY=value 键值对，存储配置信息并系统/会话范围内有效，如 PATH、HOME、USER。
- 通过 export 声明，printenv 查询。
- 敏感信息如数据库账号密码推荐用环境变量而非写入代码，配置可分环境（dev/test/prod）分别隔离。
- 持久环境变量可编辑 bash 配置文件（如 ~/.bashrc），系统级变量存于 /etc/environment。
- PATH 环境变量决定命令查找路径。

***

网络

- LAN（局域网）、WAN（广域网）、IP 地址、子网掩码、路由器与网关基本概念。
- NAT 使局域网私有地址映射为公网地址，提升安全与地址利用。
- 防火墙规则可限制端口与访问源，常见端口如 80(HTTP)、3306(MySQL)、5432(Postgres)。

***

DNS

- DNS 实现域名到 IP 地址的解析，是互联网的“电话簿”。
- 域名注册、顶级域、权威解析过程简介。
- 常见网络命令：ifconfig、netstat、ps aux、nslookup、ping。

***

SSH（安全 Shell）

- SSH 是安全远程登录协议，用于管理远程服务器。
- 支持用户名/密码和密钥对两种认证方式，推荐用密钥。
- 远程服务器配置和自动化也常用 SSH。
- SSH 默认端口 22，公钥管理于 ~/.ssh/authorized_keys。

***

安全最佳实践摘要

- 只用 root 管理系统，常用普通用户+sudo 提权。
- 强密码、定期更换、限制登录失败次数。
- 只开必要端口与服务，定期更新软件，停用未用服务。
- 避免 root SSH 登录。
- 推荐 Bash 脚本管理和“防火墙+自动化”组合提升安全性。
