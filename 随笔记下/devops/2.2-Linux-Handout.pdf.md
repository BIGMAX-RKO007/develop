操作系统与 Linux 基础

操作系统简介

什么是操作系统？
应用（如浏览器）不是直接与计算机硬件交互，而是通过操作系统作为两者之间的抽象层。
如果每个应用都必须直接与硬件部分交互会非常混乱。
像浏览器这样的应用无法直接安装到硬件上。
操作系统作为应用和硬件之间的抽象层。
操作系统是用于管理计算机硬件、软件资源，并为计算机程序提供通用服务的软件。

进程管理（CPU）：
一个 CPU 一次只能处理一个任务。
操作系统决定哪个进程获得处理器（CPU）、何时获得以及分配多少时间。
处理器切换任务的速度非常快，你几乎察觉不到。

内存管理（RAM）：
为应用分配工作内存（RAM）。
计算机上的 RAM 有限。
操作系统在应用之间管理资源。

操作系统的任务 - 1

1) 资源分配和管理

存储管理（硬盘）：
也称“二级存储”——即硬盘。
用于长期存储数据，如文件、浏览器配置、游戏、图片、视频等。

操作系统的任务 - 2
2) 文件管理

- 文件以结构化方式存储。
- 文件系统被组织为目录结构。
- Unix 系统是树形文件系统。
- Windows 操作系统有多个根目录。

3) 设备管理

- 通过各自驱动程序管理设备通信。
- 相关活动包括：
    - 追踪所有设备
    - 决定哪个进程获取设备、何时以及持续多长时间

安全性：
管理用户和权限。
每个用户都有自己的空间和权限。

网络：
端口和 IP 地址。
将所有应用端口的出站数据传送至网络，并将到达的网络数据包转发给相应进程。
