DEVOPS 先修知识

入门级别

1 - DevOps 先修知识
2 - DevOps 基础
3 - DevOps 核心
4 - DevOps 进阶

第 1 周
每周进度跟踪
开始 Linux - 2.01：操作系统简介
结束 Linux - 2.14：Shell 脚本（三）——概念与语法

本周重点主题

- 操作系统与虚拟机基础：操作系统类型、内存（RAM）、存储以及虚拟机（Type 1 与 Type 2）的概览
- 命令行接口与命令：关键 Linux 命令（pwd、ls、rm），图形界面（GUI）与命令行（CLI）的对比
- 用户与文件管理：创建用户、设置权限、管理文件归属（chown）
- Shell 脚本：用条件、函数及最佳实践编写 bash 脚本

本周自查清单

- 在 VirtualBox 上完成 Ubuntu 虚拟机的安装
- 练习 Linux 常用命令

推荐与提示

- 记得：确保为 VirtualBox 内的 Ubuntu 虚拟机分配足够的系统资源。
- 提示：本模块的 GitLab 仓库包含大量有用的命令行指令，务必查看！

第 2 周
每周进度跟踪
开始 Linux - 2.15：环境变量
结束 Git - 3.13：历史回溯

本周重点主题

- 环境变量：定义和输出环境变量，及其应用场景
- 网络基础：IP 地址，子网划分，NAT，防火墙和 DNS 基础
- 版本控制概述：理解版本控制、合并、冲突处理及最佳实践
- Git 命令：练习基础 Git 命令——git add、git commit、git log、git pull
- 分支与冲突：管理分支，创建与解决合并冲突，练习文件暂存（stash）

本周自查清单

- 配置环境变量，并在脚本中练习使用
- 创建 DigitalOcean 云主机并通过 SSH 连接
- 练习基础 Git 命令
- 操作多分支，解决合并冲突

推荐与提示

- 提示：本周结束后可销毁 DigitalOcean 云主机，并删除 VirtualBox 下的 Ubuntu 虚拟机，两者在后续 Bootcamp 中不会再用到！

第 3 周
每周进度跟踪
开始 Git - 3.14：撤销提交
结束 Build Tools - 4.13：DevOps 构建工具

本周重点主题

- 分支合并：练习合并 bugfix 和 master 分支
- 软件开发中的数据库：本地与远程数据库概览，配置数据库连接及生产环境的数据库管理最佳实践
- 数据库类型：介绍不同数据库类型（键值型、宽表、文档型、关系型、图数据库和搜索数据库）及其在现代应用中的用例
- 构建工具：理解 Maven、Gradle 等构建工具的作用与应用场景
- Windows 与 Linux 命令行差异：学习两者的主要区别
- 包管理：探索 Maven 的 pom.xml、Gradle 的 build.gradle 及 package.json 的依赖管理
- DevOps 的构建工具：理解 Docker 如何简化构建流程，包括 Dockerfile 实例，并如何集成到 CI/CD 流水线中

本周自查清单

- 合并 bugfix 与 master 分支并解决冲突
- 在本地安装 IntelliJ IDEA、Java SDK、Node.js 和 Git
- 构建 Maven 与 Gradle 应用
- 理解并检查 pom.xml、build.gradle 和 package.json

推荐与提示

- 提示：Mac 用户无需完成 Windows 相关课程，反之亦然！
- 提醒：在 Windows 安装工具时，务必妥善配置 PATH 环境变量，以避免命令执行出错。
- 提示：确保安装与演示一致版本的 Gradle 与 Java。
