# 5.2-Cloud-Basics-IaaS-Handout.pdf

下面是《5.2 Cloud Basics \& IaaS Handout.pdf》的详细中文翻译：

***

云与基础设施即服务（IaaS）

在整个 DevOps 训练营过程中，我们会安装和配置：

- Nexus 制品仓库 （artifact repository）
- Jenkins 持续集成/构建工具
- 以及部署自有应用等

这些服务不会安装在本地笔记本电脑！更加真实的做法是：把它们装在云上的远端专用服务器上。

***

什么是基础设施即服务（IaaS）?

- IaaS 提供按需分配计算、存储和网络资源。
- 区别于企业自行购置服务器，IaaS 让你把物理基础设施搬上云端，只需按需租用服务器。
- 你自己管理服务器和基础设施，任何问题也需自行运维修复。
- 即 “把自己的物理硬件移到云上”，不用自己买硬件，只用按需租服务器。

***

什么是云计算？

- 云计算是通过互联网（即“云端”）交付计算服务，包括服务器、存储、数据库、网络和软件等。
- IaaS 是四类云服务之一，其他三类为：SaaS（软件即服务）、PaaS（平台即服务）和 Serverless（无服务器）。

***

主流 IaaS 提供商

- AWS（最常用，强大但复杂，后续模块详细讲解）
- DigitalOcean（入门简单，上手快）

***

准备工作

1. 注册 DigitalOcean 账号（新用户有免费额度）
2. 配置 SSH 密钥
3. 用 Linux Ubuntu 镜像创建 Droplet 云主机
4. 用防火墙开放服务器 SSH 22 端口
5. 通过公有 IP 地址用 SSH 链接到服务器
6. 安装 Java 以运行 Java 应用

***

在 DigitalOcean 上搭建服务器（以运行打包后的 Java 应用为例）

服务器在 DigitalOcean 上称为 “Droplet”，Droplet 是基于 Linux 的虚拟机（VM）。

***

设置 SSH 密钥

- 要实现在本地用 SSH 连接 DO 上任意服务器，需配置 SSH 公钥和私钥对。

***

创建 Droplet

- 选择 Linux Ubuntu 发行版，创建云主机。

***

配置防火墙，开放 SSH 22 端口

- 通过新建防火墙配置，为服务器开放 22 端口。
- 入站规则（inbound）：允许外部访问。
- 出站规则（outbound）：服务器访问外部。

***

用 SSH 连接服务器

- 使用 Droplet 公有 IP 地址，通过 SSH 登录远端服务器。

***

安装 Java 环境

1. 检查是否已安装 Java，确认安装命令。
2. 安装 Java 以运行 Java 应用。

***

典型 Java 应用部署操作

1. 本地用 gradle build 命令构建 jar 文件。
2. 用 scp 命令将 jar 文件复制到远程服务器（如 root@服务器IP:/root 路径）。
3. 用 java -jar 命令在服务器上运行 jar 包，正常输出即说明 Java 应用已在云服务器运行。

***

安全最佳实践

- 在云服务器上创建独立的 Linux 用户（详见 Linux 模块），不同服务独立账号。
- 每个平台服务器配置有差异，Droplet 默认用 root 登录，实际应新建 “admin” 用户，再为每个应用（如 nexus、jenkins、my-app）各建单独账号。
- 最小权限原则：只赋予运行必备权限。不直接用 root 用户操作应用！
