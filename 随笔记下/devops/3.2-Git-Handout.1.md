***

使用 Git 进行版本控制

什么是版本控制？

- 又称“源码管理”，指追踪和管理软件代码变更的实践。
- 允许多人同时在同一项目上协作开发。
- 代码库（Repository）：代码集中托管在互联网上。每位开发者本地都会有一份完整代码副本。

***

版本控制基本概念

- 版本控制会保留所有变更历史。
- 每一次代码变动和每个文件都会被追踪！
- 可以撤回（revert）某一次提交。
- 每一次改动都有说明信息（commit message）。

***

Git 是最常用的版本控制系统。

***

Git 基本概念 - 1

- 远程仓库：托管代码的平台，如 Gitlab 或 GitHub。
- 本地仓库：你电脑上的代码副本。
- Git 客户端：用于连接仓库和执行 Git 命令（图形界面或命令行工具）。
- 本地仓库与远程仓库之间执行拉取（pull）和推送（push）。

***

Git 基本概念 - 2

- 绝大多数时候，Git 能自动合并更改。
- 但如果多人在同一行代码有更改，就会产生“合并冲突”，需要你手动处理。
- 最佳实践：经常 push 和 pull 与远程仓库同步，减少冲突。
- 备注：只有拉取最新代码后，本地才会受到远程破坏性更新的影响。

***

使用 Git 工作 - 1

- git add <file>：将文件的更改纳入下次提交，将变动从“工作区”移到“暂存区”。
- git commit -m "commit message"：保存更改于本地仓库，创建一个可回溯的提交快照。

***

使用 Git 工作 - 2

- git push <remote> <branch-name>：将本地提交推送到远程仓库。
