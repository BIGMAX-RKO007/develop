第8周
每周进度跟踪
起步 Jenkins - 08.01：自动化构建简介
结束 Jenkins - 08.07：从 Freestyle 到 Pipeline 任务

本周重点主题

- Jenkins in Docker：在 DigitalOcean droplet 上以 Docker 容器方式部署 Jenkins
- Jenkins UI 教程：熟悉和操作 Jenkins 用户界面
- Jenkins 集成 Gradle \& Maven：掌握在 Jenkins 中用 Gradle/Maven 构建管理 Java 项目
- Jenkins Freestyle 任务：新建 freestyle 任务、连接 Git 项目、在 job 内执行 shell 命令
- Docker 集成：在 Jenkins 中安装 Docker 并运行相关命令
- Jenkins Pipeline 任务：了解 Pipeline 概念与优势及使用场景

本周自查清单

- 在 DigitalOcean droplet 上安装 Docker 并运行 Jenkins 容器
- 配置 Jenkins
- 在 Jenkins 安装 Gradle 和 Maven，验证设置
- 创建连接 Git 项目的 freestyle 任务，在任务中执行 shell 命令
- 配置 Jenkins 卷、安装 Docker、集成 Docker build/login/push 操作

推荐与提示

- 提示：编写/编辑 Jenkinsfile 时注意代码缩进
- 提示：如 Jenkins 服务器性能有问题且资源充足，尝试升级相关插件
- 提醒：如未继续 Bootcamp 练习，可以在本阶段结束后及时删除托管 Nexus 的 DigitalOcean droplet，避免不必要账单

第9周
每周进度跟踪
起步 Jenkins - 08.08：Pipeline 任务简介
结束 Jenkins - 08.15：Webhook 自动触发 Pipeline 任务

本周重点主题

- 编写 Jenkinsfile：用 Jenkinsfile 实现 CI/CD pipeline 的自动构建、测试、发布
- Jenkinsfile 进阶：多 stage 管道、添加 shell 命令、凭据、Groovy 脚本提升流水线功能
- Jenkins 凭据：理解 secret text、SSH key、用户名/密码各类凭据及适用场景
- 多分支 Pipeline：Jenkins 自动构建 Git 仓库多分支
- Groovy 脚本与 Shared Library：利用 script.groovy 实现 pipeline 复用代码库
- GitLab 集成：用 GitLab 插件配置 webhook，实现代码变更自动触发 pipeline

本周自查清单

- 编写 Jenkinsfile 实现自动化构建、测试、发布
- 实现多 stage（含 shell 命令与 Groovy 脚本）
- Jenkins pipeline 配置凭据
- 配置多分支 pipeline，处理多分支变更
- 编写 script.groovy 抽离共用代码
- Jenkins 安装 GitLab 插件并配置 webhook

推荐与提示

- 提示：Jenkinsfile 里 maven 安装名要和 Jenkins 控制台设置一致，否则报错。

第10周
每周进度跟踪
起步 Jenkins - 08.16：Jenkins流水线动态升级应用版本（Part 1）
结束 AWS - 09.05：AWS VPC 私有网络管理

本周重点主题

- pom.xml 文件：自动化版本号递增
- Jenkinsfile 版本管理：CI流水线自动递增版本号、提交、推送改动
- AWS 入门：理解 AWS 平台、IAM、VPC、免费层
- AWS 全球架构：区域与可用区

本周自查清单

- 配置 pom.xml 实现 Jenkins 构建时自动升级 java-app 项目版本
- 升级 Jenkinsfile 实现自动递增、提交并推送至 Git
- 熟悉 Jenkins UI，理解 pipeline 管理核心服务
- 配置 AWS IAM 用户/角色/组

推荐与提示

- 提醒：注意 AWS 免费额度用量，避免意外扣费

第11周
每周进度跟踪
起步 AWS - 09.06：CIDR Block 详解
结束 AWS - 09.14：AWS 容器服务入门预览

本周重点主题

- CIDR 格式、子网及网络规划（含子网计算器用法）
- EC2 实例管理：实例、密钥对、安全组
- Jenkins \& Docker 集成 EC2：流水线自动升级版本、构建镜像并推送到 EC2
- AWS CLI：命令行批量管理 AWS 基础设施
- 基础设施即代码（IaC）、微服务概念与 AWS EKS 容器编排

本周自查清单

- 用子网计算器理解 CIDR 子网划分原理
- 创建 EC2 并配置 SSH、安装 Docker、拉取镜像运行应用
- 把 EC2 SSH 密钥加入 Jenkins，升级 Jenkinsfile 实现 Docker/EC2 全流程
- 在 EC2 上装 Docker Compose，编写 docker-compose.yml 并用 Jenkins 拷贝执行
- 装配 AWS CLI、配置安全组与用命令行启动 EC2 实例

推荐与提示

- 提醒：EC2 SSH 密钥要配置正确权限
- 提示：本模块 Git 仓库含常用 AWS CLI 命令速查
