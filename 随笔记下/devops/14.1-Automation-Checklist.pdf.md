# 14.1-Automation-Checklist.pdf

以下是《14.1 Automation Checklist.pdf》内容分主题详细中文翻译，涵盖 Python 自动化与云运维/监控脚本项目清单：

***

[模块主题]
**Python 自动化运维基础**

- AWS Boto3 入门（Python AWS 开发包）
- Boto3 安装与 AWS 账号连接
- 熟悉 Boto3 API（包括查询 VPC、子网等）
- Python vs Terraform 编排模式比较

***

[项目实战方向]

1. **EC2 服务器状态监控**
    - 通过 Terraform 创建3个 EC2 实例作为准备
    - 用 Python 脚本批量打印所有实例的状态与健康检查
    - 编写计划任务（定时监控）
2. **给 EC2 实例批量打 Tag**
    - 获取指定 region 所有 EC2 实例并自动打上环境标签
3. **EKS 集群信息查询**
    - 通过 Terraform 搭建 EKS 集群及相关资源为准备工作
    - 用 Python 获取所有 EKS 集群，输出状态/Endpoint/K8s 版本等
4. **EC2 数据备份/快照/清理/恢复**
    - 列出所有 EC2 挂载的卷，创建快照（支持定时脚本与只备 production 环境）
    - 删除历史快照，仅保留最新2个（按卷分组）
    - 从快照自动恢复新卷并关联回 EC2
5. **处理脚本异常与错误**
    - 演示综合错误捕获与异常处理设计

***

[监控与告警自动化]

1. **网站监控与自愈**
    - 用 requests 库检测指定 Web 服务状态（返回非200时告警）
    - 实现异常断连时邮件报警（SMTP/邮件服务配置，环境变量管理账号）
    - 自动重启 Docker container 或 reboot 云主机
    - 支持 Linode 云API下的自动重启/远程控制与任务调度

***

***

[阶段自查清单]

- Boto3/AWS 脚本编写、EC2/EKS 快照/标签/恢复/计划任务/错误处理全流程
- 业务网站自动化状态监控、容器与主机异常自愈、告警邮件与SSH远程修复
- 每步均有对应 Git 项目代码仓库/案例/命令参考
