### Demo 项目总览与目的

这是 TechWorld with Nana 的 DevOps Bootcamp 的演示项目清单，帮助学员记录和管理不同的 Git 仓库项目，便于后续在求职时作为作品集展示。[^1]

### 主要模块与项目概览

#### 云基础设施服务入门

- 在 DigitalOcean 上创建服务器并部署 Java Gradle 应用。
- 涉及技术：DigitalOcean、Linux、Java、Gradle。
- 包括安全配置和新用户创建。


#### 构件仓库管理（Nexus）

- 在云服务器上安装与配置 Nexus。
- Java Gradle、Maven 项目打包后上传到 Nexus。
- 涉及技术：Nexus、DigitalOcean、Linux、Java、Gradle、Maven。


#### 容器与 Docker

- 为 Node.js 应用编写 Dockerfile、本地容器编排与数据持久化。
- 使用 Docker Compose 管理多个容器及服务。
- 推送 Docker 镜像到 AWS ECR 或 Nexus 私有仓库。
- 涉及技术：Docker、Node.js、MongoDB、AWS ECR、Nexus。


#### Jenkins 持续集成/持续交付

- Jenkins 安装、流水线配置、自动版本升级。
- 集成 Git、Maven、Docker 实现自动构建与部署（包括 Freestyle、Pipeline、Multibranch 管道）。
- 通过 Webhook 实现自动触发 CI。
- 使用 Jenkins Shared Library 提取复用构建逻辑。


#### AWS 服务自动化

- 手动与自动化（CI/CD Pipeline）部署应用至 EC2、EKS。
- 集成 AWS CLI、Docker Compose、Jenkins 等自动化工具。
- 自动化生成并管理 VPC、IAM、EC2 现成环境。


#### Kubernetes 容器编排

- 使用 Minikube、Linode LKE 或 AWS EKS 部署 MongoDB、微服务、消息中间件等。
- 利用 Helm、Helmfile 实现模板化部署和共享 Chart。
- 微服务安全最佳实践与生产环境配置。


#### 基础设施即代码（Terraform）

- 用 Terraform 自动创建 AWS 基础设施与资源。
- 利用模块化和远程状态存储（S3）提升可复用性与团队协作。
- 集成 Terraform 与 Jenkins，实现自动化环境搭建和应用部署。


#### Python 编程与自动化

- 开发倒计时应用、批量表格处理和 API 调用。
- 使用 Boto3 脚本自动化 AWS EC2 实例监控、标签管理和备份恢复。
- 编写网站监控与自愈、EKS 状态信息脚本。


#### 配置管理与 Ansible

- 用 Ansible Playbook 自动部署 Node.js 应用、Nexus、Docker 环境。
- 与 Terraform、Jenkins 集成实现一键化环境配置及动态主机清单。
- 优化 Playbook 结构，采用角色（Role）分模块管理。


#### 监控与 Prometheus

- 在 Kubernetes 集群中通过 Prometheus、Grafana、Alertmanager 实现监控与告警。
- 针对自主或第三方应用（如 Redis、Node.js）自定义监控指标与仪表板。
