[Python 基础概念]

- Python 是众多编程语言之一，其基础编程原理在各种语言间都很类似。
- Python 优势：
    - 简单语法，易于入门
    - 大型生态系统、丰富库与社区
    - 更好的跨领域可选项（Web开发、数据科学、AI、自动化、爬虫、桌面、移动、游戏…）
    - 安装与环境配置简单

[为什么 DevOps 工程师要学 Python]

- 编程能力，尤其是 Python，会极大提升 DevOps 工程师核心竞争力。
- 可用于：
    - 监控与自动化任务
    - 备份任务
    - 系统健康检查
    - 定制 Ansible 模块
    - 数据可视化与报表
    - 管理定时任务（Cron）

***

[核心编程知识]

- 变量与数据类型：变量可存储不同类型数据（字符串、数字等），不同类型能做不同事。

```python
score = 5
name = "James"
```

- 注释使用 \#，只在必要处添加，变量名应尽量描述含义。
- 函数（def 关键字）：用来封装可复用代码单元，可传递参数和返回结果。

```python
def add(a, b):
    return a + b
```

- 条件语句 if/else \& 布尔类型（True/False）

```python
if a > b:
    ...
elif a == b:
    ...
else:
    ...
```

- 用户输入、异常处理

```python
user_input = input("Enter a value: ")
try:
    number = int(user_input)
except ValueError:
    print("请输入数字！")
```

- 循环（for、while）
    - 列表/数组可用 for，任意元素集合可用 while。

```python
friends = ["tim", "sara", "john"]
for name in friends:
    print(name)
```


***

[复杂数据结构]

- 集合 set：存储不重复且无序数据（如学号列表）。
- 字典 dict：用 key:value 方式管理复杂结构。

```python
user = {"name": "Jim", "age": 32}
```


***

[模块与包]

- 模块是独立的 python 文件，只需 import 即可复用其中代码。
- 标准库丰富，第三方包可用 pip 安装。包目录需包含 __init__.py 文件才能被识别为包。

```python
# 创建模块 helper.py
def greet(): print("Hello")

# 在 main.py 中导入
from helper import greet
greet()
```

- 官方有大量标准库，如 datetime、threading、base64，第三方库托管于 PyPI（用 pip 安装）。

***

[面向对象编程（OOP）]

- Python 是典型 OOP 语言，几乎所有东西都是对象。
- 类 class 相当于蓝图，对象 object 是类的实例，属性存储状态，方法描述行为。

```python
class Person:
    def __init__(self, name, age):
        self.name = name
        self.age = age
p1 = Person("Jim", 32)
```


***

[API 原理与 HTTP 请求]

- API（应用编程接口）是应用之间交互的桥梁，如 GitLab 提供 API 查询用户仓库。
- Python 用 requests 库发 HTTP 请求处理 JSON 格式数据。

```python
import requests
response = requests.get("https://gitlab.com/api/v4/")
print(response.json())
```

- 私有数据需认证（如 Basic Auth），须随请求附带登录凭据，接口合理返回权限校验结果。

***

[最佳实践]

1. 命名规范：变量/函数一律用小写加下划线，类名首字母大写（user.py 文件、User 类）。
2. 常量全大写、下划线分隔，如 MAX_OVERFLOW。
3. 注释只在必要时写，变量应自解释。
4. 缩进统一用空格，函数应保持单一职责、不做多余逻辑（有太多参数应拆分）。
5. DRY 原则：所有重复的代码逻辑应抽成函数或变量，减少冗余。
