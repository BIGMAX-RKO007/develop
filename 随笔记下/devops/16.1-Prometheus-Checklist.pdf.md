# 16.1-Prometheus-Checklist.pdf

以下是《16.1-Prometheus-Checklist.pdf》的详细中文翻译，涵盖基于 Prometheus 的监控体系、Kubernetes 集成、Grafana 可视化、告警与自定义应用监控的全流程实践：

***

**Prometheus 监控体系核心流程**

***

**视频总览与本章知识点**

- Prometheus 监控简介
- 在 Kubernetes 集群中安装 Prometheus Stack
- 用 Prometheus UI 可视化和数据查询
- Grafana 入门（可视化仪表盘搭建）
- Prometheus 告警规则原理与实操（包括自定义多级告警）
- Alertmanager 基础与邮件通知配置
- 第三方系统和服务的监控集成（Exporter 技术）
- 部署 Redis Exporter 与监控
- Grafana + Prometheus 联合监控 Redis 实战
- 用 Prometheus Client Library 监控自有业务应用（Node.js 实例）
- 采集应用指标、配置自定义 Grafana Dashboard

***

**核心实验/项目与进度清单**

1. **Prometheus 栈在 K8s 安装**
    - eksctl 创建 K8s/EKS 集群，部署微服务及 Prometheus Stack
    - 使用官方 Helm Chart 一键部署
    - 探索 Prometheus Stack 各功能组件
2. **Prometheus UI 与 Grafana 可视化**
    - 访问 Prometheus UI，探索各采集端点与表达式查询
    - 访问 Grafana，测试 CPU 峰值等动态行为
    - 官方 Grafana Dashboards 文档与示例路径
        - https://grafana.com/docs/grafana/latest/dashboards/
3. **Prometheus 告警规则与 Alertmanager 实践**
    - 创建自定义 PrometheusRule，添加多条 Alert 规则（yaml 格式）
    - 多级多条件分组告警测试
    - 官方 Alerting 规则文档
        - https://prometheus.io/docs/alerting/latest/overview/
        - https://docs.openshift.com/container-platform/4.16/rest_api/monitoring_apis/prometheusrule-monitoring-coreos-com-v1.html
    - Alertmanager 邮件通知：
        - 配置邮件接收人，实现告警触发后的自动邮件发送
        - 官方 Alertmanager 配置样例
            - https://prometheus.io/docs/alerting/latest/alertmanager/
            - https://prometheus.io/docs/alerting/latest/configuration/

***

4. **第三方服务监控与 Redis 实践**
    - 集成多种 Exporter（如 node_exporter、redis_exporter）采集三方系统或中间件指标
    - Redis Exporter 部署 Demo 与实用 Helm Chart
        - https://github.com/prometheus-community/helm-charts/tree/main/charts/prometheus-redis-exporter
    - 配套告警规则与 Grafana Dashboard 导入
        - https://awesome-prometheus-alerts.grep.to/
        - https://grafana.com/grafana/dashboards
        - Redis Dashboard 示例: https://grafana.com/grafana/dashboards/763

***

5. **自定义应用监控开发（以 Node.js 为例）**
    - 使用 Prometheus Client Library 编写业务应用的代码级自定义指标采集
        - 官方 Client Library 列表 https://prometheus.io/docs/instrumenting/clientlibs/
        - Nodejs Prometheus Client 示例：https://www.npmjs.com/package/prom-client
        - 项目实践与源码仓库：https://gitlab.com/twn-devops-bootcamp/latest/16-prometheus/nodejs-app-monitoring
    - 应用部署流程：
        - 制作 Docker 镜像并推送镜像仓库
        - 创建 Deployment/Service/Secret 并部署应用至 K8s
    - 配置 ServiceMonitor 实现应用指标采集
    - Grafana 新建 Dashboard，业务指标可视化
    - PromQL 表达式与速查
        - https://prometheus.io/docs/prometheus/latest/querying/functions/\#rate
