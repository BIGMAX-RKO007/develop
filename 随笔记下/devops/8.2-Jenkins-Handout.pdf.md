自动化构建 \& Jenkins 持续集成/持续交付

自动化构建简介

- 自动化构建即：自动化完成源码获取、自动执行测试、编译成二进制构建/构建 Docker 镜像、产物部署（上传）等一系列过程。
- 自动化构建与 CI/CD（持续集成/持续部署）是 DevOps 的核心。
- 手动每次做这些事极其低效，因此需要专门服务器自动执行。

实际流程

- 自动暂存代码变动并切主分支
- 登录目标 Docker 仓库
- 搭建测试环境
- 自动运行测试（测试过程代码无法继续写）
- 构建 Docker 镜像并推送仓库
- 环境准备、凭据配置、依赖安装，一键自动完成

***

什么是 CI/CD？

- CI/CD 即持续集成 / 持续部署。
- 目标：频繁小步快发，方法：将整个发布流程自动化。
- CI：新代码更改被持续构建、自动测试，并集成到公共仓库
- CD：自动持续部署到多环境，直到生产环境也能全自动上线
- 构建自动化是 CI/CD 流水线的基础模块。

***

Jenkins = 行业最常用 CI/CD 工具

- 除此之外还有 GitHub Actions、GitLab CI、CircleCI 等

***

Jenkins 简介

- Jenkins 是安装在专用服务器上的软件，Web 界面可配置所有构建流程。
- 需要手动安装 docker、gradle/maven/npm 等第三方工具。
- 配置完成后可自动化运行测试、构建应用、自动部署等其他任务。
- 每个任务可配置自动触发条件（如 push、定时、Webhook）。

Jenkins 支持的功能举例

- 自动部署产物、自动化测试、构建产物、产物发布、消息通知等
- Jenkins 的核心：插件机制（Plugins），支持 Docker、代码仓库、各种构建与部署工具扩展
- 插件帮你实现 DevOps 全流程的每一环节
- 管理员可运维 Jenkins（插件、配置、维护），开发/运维工程师可以新建 workflow jobs。

***

Jenkins 管理与分工

- 管理员（Operations/DevOps）：负责运维、集群搭建、插件安装及数据备份
- 开发/DevOps 工程师：负责编写具体 build job（workflow）

***

Jenkins 常见体系结构与核心概念

- 节点（Nodes）\& 云（Clouds）：分布式执行流水线
- 工具（Tools）：配置并自动安装构建相关工具，如 maven、npm
- 安全设置：全局权限/用户/凭据管理
- 插件管理：插件增删、启用/禁用、升级
- 凭据管理：配置不同凭据用于自动化拉取代码、登录仓库等
- Freestyle Project, Pipeline, Multi-config, Multibranch Pipeline, Folders, Org Folder：主要项目/任务类型

***

自动化构建 \& Jenkins 持续集成/持续交付

自动化构建简介

- 自动化构建是指自动完成：源码拉取、自动测试、编译成二进制或 Docker 镜像、产物部署等全过程。
- 自动化构建和 CI/CD（持续集成/持续部署）是 DevOps 的核心。
- 如果每次手动做这些事情会非常麻烦，所以我们有专用服务器来自动做这些事。

实际自动化流程举例

- 暂存代码变更并切回主分支
- 登录合适的 docker 仓库
- 准备测试环境并运行测试（期间不能继续开发）
- 构建 Docker 镜像并推送至仓库
- 测试环境、Docker 认证、工具全部就绪，一切自动触发

***

什么是 CI/CD？

- CI/CD = 持续集成 / 持续交付。目标是“快速迭代、小步快发”，做法是自动化整个发布流程。
- CI：新代码持续集成到主干，自动构建与测试并及时合并。
- CD：自动部署到预生产、生产等各种环境。
- 自动化构建是 CI/CD 流水线的基础模块。

***

Jenkins - 行业最流行的 CI/CD 工具

- 还有 GitHub Actions、GitLab CI 等

***

Jenkins 简介

- Jenkins 是需要装在独立服务器上的工具，提供 Web UI 配置各种 job。
- 任务通常包括拉代码、安装依赖、测试、构建、部署等流程。
- 你要安装所有依赖工具（如 Docker/Gradle/Maven/npm 等），才能完成各个任务。
- 配置完成后，要定义什么时候自动触发任务。

***

Jenkins 能做什么

- 自动部署
- 运行测试
- 构建发布产物
- 发送通知
- ……

***

Jenkins 依赖插件实现对各环节的集成。

- Docker/Build Tools/仓库/部署服务器等功能均靠插件实现。
- 插件扩展 Jenkins 功能，帮助你实现各环节的自动化运维。

***

DevOps 工程师工作实践

- 常被要求运维 Jenkins（如插件安装、服务设置），或帮开发团队配置 job，并解决自动化相关流程问题。
