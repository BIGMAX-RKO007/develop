# 14.2-Automation-Handout.pdf

以下是《14.2 Automation Handout.pdf》的详细中文翻译，总结 Python 在 AWS 自动化运维场景的关键知识、项目范例与最佳实践：

***

**用 Python 自动化云端运维（以 AWS 为例）**

***

**自动化目标：**

- 自动备份（定时快照、数据卷）
- 自动清理（如定期删除旧快照/资源等）
- 配置/调整现有服务器
- 健康检查与自动化监控
- 规模化维护（成百上千台服务器/集群）

***

**Boto3 简介（AWS Python 开发包）**

- Boto3 是 AWS 官方 Python SDK，支持对 EC2、S3 等所有主流服务的自动控制与脚本化操作。
- 调用前需配置 AWS 认证凭据（~/.aws/credentials 和 config）。
- 支持两种 API 方式：
    - 低级: `ec2_client = boto3.client('ec2', region_name="eu-central-1")`
    - 面向对象: `ec2_resource = boto3.resource('ec2', region_name="eu-central-1")`
- Azure/Google Cloud 需用对应 SDK。

***

**Terraform 与 Python 自动化的区别**

- **Terraform**：
    - 对云资源有完整“状态感知”，声明式描述目标状态。
    - 幂等性强（多次 apply 结果一致）。
    - 自动资源比对、推荐用作基础设施编排。
- **Python 脚本**：
    - 不自带状态管理（需自己处理重复、幂等、变更影响）。
    - 必须显式逐步写明动作（命令式/过程导向）。
    - 灵活，高度可编程，适合监控/数据流/复杂流程控制。

***

**自动化任务与 Python 项目示例**

1. **EC2 状态检查**：
    - 脚本自动输出所有 EC2 实例当前状态与健康状况。
    - 支持定时调度器（如 schedule.every(5).seconds.do(...)，实现自动周期状态汇报）。
2. **批量打标签**：
    - 大规模实例自动加环境标签（如 environment=dev/production），用于资源分类。
3. **EKS 集群信息批量获取**：
    - 查询所有 Kubernetes 集群状态与版本等关键信息。
4. **数据卷快照自动备份/清理/恢复**：
    - 每台实例驱动定时快照（PYTHON 定时脚本），批量统一或分 region/环境处理。
    - 自动清理旧的快照（如最多仅保留2个新快照），避免存储费用激增。
    - 恢复流程：指定快照ID，创建新数据卷并重新挂载至 EC2，实现一键数据恢复。
5. **网站监控/自愈 \& 告警**
    - 用 Python 定时发 HTTP 请求检测业务站点状态。
    - 站点异常自动邮件报警（SMTP 账号存于环境变量，防硬编码）。
    - 可自动远程重启 Docker 容器或整台云主机（用 paramiko、linode-api 等库）。
6. **异常与错误处理机制**
    - 全业务流程必做失败兜底重试、错误输出与告警日志。
    - 示例：创建快照失败应自动删除并重试，而不是任由失败积压。

***

**注意事项与最佳实践**

- Python 属于无状态设计，幂等/去重/流程健壮性需脚本自行保证；Terraform 状态管理全自动，适合大资源集群。
- 脚本必须区分单步错误与全流程失败，所有动作宜有日志与告警通道。
- 尽量用 schedule 等库实现定时调用/自动轮询/弹性任务调度。
